# 在 STEPX Neo 上用手机安装 GBox 并登录 Google Play

版本 v1.0.0，整理于 2026-10-18。阅读顺序：准备 → 下载 → 安装 → 配置 → 登录 → 装应用 → 验收。

## 1. 先确认目标和适用范围

目标是打开 GBox 内的 Google Play 商店，登录自己的账号并安装应用。GBox 提供容器环境，不会把缺失的系统特权授予手机里另外安装的 Google Play 服务。

本次成功组合为 STEPX Neo / StepX PZ261A、Android 16、StepAOS 1.0.0.2、GBox 1.8.4.02。系统更新后表现可能不同。

**本次实测使用 ADB 辅助安装 APK，但最终联网和日常使用依靠手机本身。本文把下载与安装改写为手机浏览器操作，没有要求运行任何电脑命令；全新出厂设备的全流程手机独立复测仍待补充。** 实测手机此前进行过原生 GMS 试验，详见仓库的[实测记录](https://github.com/JiayuStudio/stepx-neo-gbox-guide/blob/main/docs/实测记录.md)。

## 2. 准备手机、账号和网络

准备好以下内容：

- 手机浏览器和文件管理器。
- 自己的 Google 账号；若启用了两步验证，准备好已绑定设备、验证器或其他可用验证方式。
- 手机自身可访问 Google 的网络。电脑能访问不代表手机也能访问；仅浏览器有代理，也不一定覆盖 GBox。
- 足够的存储空间。GBox APK 约 124 MB，安装后的容器和后续应用还会继续占用空间，建议预留数 GB。

先完成网络检查：

1. 打开手机上已在使用的网络工具，确认连接成功。
2. 用手机浏览器打开 [accounts.google.com](https://accounts.google.com/)，应当看到可正常加载的 Google 登录页面。
3. 如果网络工具按应用分流，确保 **GBox** 也使用可访问 Google 的连接。首次安装后它可能尚未进入原有应用名单，需要检查一次。
4. 浏览器打不开时，先处理网络；暂时不要反复重装 GBox。浏览器成功只是初步检查，最终仍以容器内能加载登录页为准。

网络账号、订阅和节点由用户自行配置。本教程不需要也不提供他人的代理配置。

## 3. 直接用手机下载 GBox

推荐使用官网：

1. 在手机浏览器打开 [GBox 官网](https://www.gboxlab.com/)。
2. 找到 **Stable Version / 稳定版**。本教程核验版本为 **1.8.4.02**，官网当时标注更新日期 2026-09-22。
3. 点击下载；若浏览器提示 APK 文件可能有风险，先核对网站和文件来源，再按自己的判断选择保留。
4. 等待下载完成，在浏览器的“下载”列表或文件管理器的 Download/下载目录找到文件。

本次官网原始链接：

[下载 GBox 1.8.4.02 官方 APK](https://agile-files.gboxlab.com/GBox-1.8.4.02-1080402-7899902-website.apk)

官网文件名是 `GBox-1.8.4.02-1080402-7899902-website.apk`；私有归档重命名为 `GBox-1.8.4.02-official.apk`。两者应当具有相同的字节内容。不要把 GitHub 的 **Source code (zip)** 当作 APK。

如果官网之后提供了新版本，先查看仓库是否已经更新实测记录。新版本不应继续使用旧版本的校验值。

### 可选：在手机上检查文件

## 4. 安装 APK

1. 点开刚下载的 APK。
2. 若手机提示当前来源不允许安装，点“设置”，在对应页面为**刚才使用的浏览器或文件管理器**开启“允许来自此来源的应用 / 安装未知应用”。不同系统的文字可能稍有区别。
3. 返回安装界面，核对应用名为 **GBox**，点击安装。
4. 出现“安装完成”后点击打开。
5. 完成安装后，可以回到同一个来源权限页面，把刚才临时开启的未知应用安装权限关闭；以后更新时按需再开。

本流程不需要开发者选项、USB 调试、OEM 解锁、ROOT 管理器或系统刷写工具。如果出现“应用未安装”、包冲突或安全检测明确阻止，先记录原文并核对包来源，不要因此关闭整个手机的安全防护。

如果已经安装同一个官方签名的 GBox，可按系统提供的更新流程处理，保留现有数据。若提示签名冲突，不要先卸载已有 GBox：卸载可能同时移除容器应用和登录状态。

## 5. 完成首次配置

以下来自本次 1.8.4.02 实机向导。不同语言和系统版本的顺序可能变化，以弹窗实际用途为准。

| 提示 | 本次操作 / 建议 |
| --- | --- |
| 用户协议与隐私政策 | 打开阅读，接受后继续；不同意则退出使用 |
| 读取已安装应用列表 | 本机选择“仅在使用时允许” |
| 媒体和文件权限 | 按向导给予必要权限；本机弹窗涉及照片、视频、音频和文件 |
| 允许后台运行 / 电池优化 | 本机允许 GBox 在后台运行，避免初始化或登录时被终止 |
| HMS Core 安装邀请 | 本次取消，没有安装；它不是这台手机完成 Play 登录的已证实前提 |
| 通知权限 | 需要 Gmail 等通知时开启，之后再实际测试送达情况 |
| 麦克风、相机、定位、通讯录 | 按后续应用真正使用的功能再决定，不必为打开商店一次性全部授权 |

本次网络连通后，容器内出现过 **microG 服务** 的账号连接界面。这不等于还需要把另外下载的 microG、原版 GMS 或框架装进手机系统。本教程按已经成功的容器路线继续。

GBox 官网版本可能显示广告。广告中的下载按钮、推广应用和付费页面不属于本教程的安装步骤。

## 6. 在 GBox 里打开商店并登录

1. 再确认手机可访问 Google 的网络已经连接，并覆盖 GBox。
2. 进入 **GBox 首页**，点击里面的 **Google Play 商店**。不要从此前单独安装、会闪退的宿主 Play 图标进入。
3. 首次可能显示“初始化 GMS 服务”或“正在建立到 Google 服务器的连接”。保持网络稳定，等待页面继续。
4. 出现 Google 登录页后，在手机上输入自己的账号和密码，完成两步验证。
5. 根据登录页面的实际提示完成设置。看到商店首页、搜索栏和已登录的账号入口后，再进行下一步。

如果一直停在连接页面，按[故障处理](https://github.com/JiayuStudio/stepx-neo-gbox-guide/blob/main/docs/常见问题.md)先检查网络覆盖，再退出 GBox 并重新打开。不要把“清除数据”当作重启按钮。

账号验证只在自己确认的登录页面完成。不要把密码、验证码或恢复码交给教程作者或社区反馈者。如果 Google 发出新设备提醒，核对时间和刚才的操作；GBox 的虚拟环境可能显示不同设备名称，无法对应本人操作的提醒不要直接确认。

## 7. 安装第一个应用

1. 在刚打开的 Play 商店里搜索一个你要用的应用，例如 Gmail。
2. 核对应用名称、开发者和图标，点击“安装”。
3. 等待按钮变成“打开”，然后打开一次。
4. 返回 GBox，确认“已安装应用”里出现该应用。
5. 后续优先从 GBox 的已安装列表进入；如需桌面图标，再使用 GBox 提供的快捷方式功能。

如果出现“安装到设备 / Install to Device / Install to Real Device”之类的选项，本教程目标是在 **GBox 内**运行。可检查 GBox 设置中的对应选项并关闭安装到宿主设备的功能；菜单位置依版本而异。这个选项依据官方 FAQ 整理，本次没有单独验证切换行为。

本次在 GBox 列表中观察到 YouTube Music、Gmail、云端硬盘、YouTube、Google、ChatGPT、相册；Play 中 Gmail 显示“打开 / 卸载”，ChatGPT 显示“已安装”。这证明安装状态，**不代表以上应用的所有功能、付款、推送和后台同步均已通过测试**。

## 8. 按这张表验收

| 检查 | 通过条件 |
| --- | --- |
| 手机独立联网 | 不接电脑，手机网络可加载 Google 登录页 |
| Play 登录 | 从 GBox 打开 Play，看到已登录状态和可加载的商店内容 |
| 安装应用 | 选定应用完成下载，按钮变为“打开” |
| 容器入口 | 该应用出现在 GBox“已安装应用”里 |
| 实际使用 | 打开该应用，完成自己所需的一个基本功能 |
| 重新打开 | 退出再进入 GBox，登录和应用仍在 |
| 持续使用 | 手机重启后重连必要网络，再检查 GBox 和目标应用 |

最后一项以及各种应用的后台通知、同步，应由使用者按自己的需求继续测试。单次打开商店不能代替这些验收。

## 9. 日常更新、清理和退出

- GBox 本体优先从官网更新。容器里的应用从容器内 Play 更新，更新后复验自己常用功能。
- 若之前装过闪退的独立 Play、Google Play 服务、Google 服务框架，先确认 GBox 已通过验收，再按故障文档的限定范围清理。
- 清理缓存、终止进程与清除应用数据不是一回事。**清除 GBox 数据或卸载 GBox 会影响容器内应用、登录状态和未同步数据。** 需要移除容器时先导出、同步所需资料。
- 桌面快捷方式被删除，不等于容器内应用已经卸载。要移除容器应用，在 GBox 的应用列表里使用相应卸载功能。
